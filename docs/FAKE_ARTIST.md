# 가짜 예술가 찾기 — 규칙 · 구현 · 보안

그림 이어말하기와 같은 클래스·방·방장 구조 위에 얹은 두 번째 게임 모드입니다 (`gameMode: 'FAKE_ARTIST'`).
그림 이어말하기(`'TELESTRATION'`)는 그대로 남아 있고 기본값입니다.

> 이 모드는 '가짜 예술가' 류 보드게임에서 착안해 **수업용으로 바꾼 온라인 규칙**입니다.
> 공식 제품의 인원수·출제자 역할·점수·세부 판정과 같지 않으며, 같다고 소개하지 않습니다.

## 1. 수업용 온라인 규칙

| 항목 | 규칙 |
|---|---|
| 인원 | 4~12명. 참관 방장·교사는 플레이어가 아닙니다. 함께 참여하는 방장은 플레이어에 포함됩니다. |
| 출제자 | 없습니다. **서버가** 고른 분류 안에서 제시어를 뽑습니다 (최근 40개 판에 나온 말은 피함). |
| 가짜 예술가 | 정확히 **한 명**을 균등 확률로 뽑습니다. 특정 학생으로 고정하지 않습니다. |
| 카드 | 예술가는 분류 + 제시어, 가짜는 분류 + "당신은 가짜 예술가입니다" 만 받습니다. 카드 확인 10초 (모두 확인하면 바로 진행). |
| 순서 | 게임 시작 때 한 번 섞어 정하고, 두 바퀴 모두 같은 순서입니다. 총 차례 수 = 2 × 인원. |
| 한 획 | 펜을 대서 떼기까지 이어진 경로 하나. 곡선·꺾인 선·닫힌 도형·점은 되고, 두 번째 경로는 안 됩니다. |
| 차례 시간 | 15 / 20 / 30초 (기본 20초). 펜을 뗀 뒤 **확정** 또는 **지우고 다시 그리기**. |
| 시간 초과 | 서버에 도착한 가장 최신의 유효한 경로를 확정합니다. 아무 것도 없으면 그 차례는 건너뜁니다. |
| 토론 | 0 / 30 / 60초 (기본 30초). 앱에 채팅은 없습니다 — 교실에서는 말로, 원격이면 쓰던 통화 도구로. 0초면 바로 투표. |
| 투표 | 20초 비공개. 자기 자신 금지, 확정 뒤 변경 금지, 안 하면 기권. 진행 중에는 "투표한 사람 수" 만 보입니다. |
| 발각 판정 | 가짜가 **단독 최다 득표** → 발각. 다른 사람이 단독 최다이거나 **동률** → 발각 실패. 유효 투표 0표 → **투표 불성립**(승패 없음). 재투표 없음. |
| 최종 추측 | 투표가 끝나면 **누구에게나 똑같이 20초**. 그동안 가짜만 제시어를 한 번 적어 낼 수 있습니다. 일찍 내도 시간이 줄지 않습니다. |
| 결과 | 발각 + 정답 → **가짜 역전 승리**, 발각 + 오답·무응답 → **예술가 팀 승리**, 발각 실패 → **가짜 승리** (추측은 재미로만 공개), 투표 불성립 → 승패 없음. |
| 점수 | 점수·순위는 없습니다. 이번 판의 승패만 보여 줍니다. |

### 정답 판정

서버가 합니다. 입력과 정답 목록(제시어 + 미리 등록한 동의어)에 똑같이

1. 유니코드 NFKC 정규화 (전각 문자 → 반각 등)
2. 앞뒤 공백 제거, 연속 공백 하나로
3. 영문 소문자화
4. 띄어쓰기 무시

를 한 뒤 **글자가 같을 때만** 정답입니다. 비슷한 말·오타를 봐주는 AI·유사도 판정은 없습니다.
예: 제시어 `아이스크림` 에 `아이스 크림`, ` 아이스크림 ` 은 정답, `아이스크린` 은 오답.

## 2. 진행 순서와 권한

```
LOBBY ─game.start→ ROLE_REVEAL ─(10초 또는 전원 확인)→ DRAWING ×2N ─→ DISCUSSION(0이면 생략)
      → VOTING ─(20초 또는 전원 투표)→ FINAL_GUESS(항상 20초) → REVEAL_READY
      ─fa.reveal.start→ REVEALING(0단계) ─fa.reveal.next ×4→ FINISHED
```

- 모든 단계 전환은 서버의 `phaseId` 가 맞을 때 **한 번만** 일어납니다. 알람·조기 종료·확정 요청이 겹쳐도 두 번 넘어가지 않습니다. 요청을 처리하기 전에 지난 기한을 먼저 따라잡습니다.
- 결과 공개는 방장(또는 진행권을 인수한 교사)만, **한 단계씩 앞으로만** 넘깁니다.
  0 완성 그림 → 1 투표 결과 → 2 가짜 예술가 → 3 최종 추측 → 4 제시어·승패.
- 4단계 뒤(FINISHED) 방장은 한 참가자를 골라 그 사람의 두 획을 모두의 화면에서 강조할 수 있습니다 (그림 데이터는 그대로, 보이는 방식만 바뀜).
- 끝나면 방장이 **같은 모드로 다시 하기** / **대기실에서 게임 종류 바꾸기** / **방 닫기** 중에서 고릅니다. 다시 하면 펜 색은 유지되고 준비·제시어·가짜는 새로 정합니다.
- 게임 종류는 대기실에서만 바꿀 수 있습니다. 바꾸면 모두의 준비 상태와 펜 색이 초기화됩니다.
- 참관 방장·교사의 실시간 모니터링은 이 모드에서 쓰지 않습니다 — 캔버스가 원래 모두에게 공개되기 때문입니다. 참관자도 카드·투표·추측은 공개 전까지 보지 못합니다.

## 3. 펜 색

- 12색 중 한 명당 하나. 대기실에서 먼저 고른 사람이 가집니다 (Durable Object 가 요청을 하나씩 처리하므로 동시에 눌러도 한 명만 성공, 나머지에게는 "○○ 님이 이미 고른 색이에요").
- 색을 고르지 않으면 준비할 수 없고, 게임이 시작되면 바꿀 수 없습니다.
- 굵기는 모두 8로 같습니다. 서버는 자기 색이 아닌 획, 지우개, 다른 굵기, 300점 초과, 여러 경로를 거부합니다.
- 색만으로 구분하지 않도록 참가자 번호·이름·색 이름을 함께 보여 줍니다.

## 4. 비밀 정보가 새지 않게 한 방법

1. **따로 저장**: 공개 상태(`meta.fa`: 순서, 색, 확정된 획, 차례, 공개 단계)와 비밀 상태(`faSecret`: 제시어, 동의어, 가짜, 표, 최종 추측, 판정)를 Durable Object 저장소의 서로 다른 키에 두고, 한 번의 `storage.put` 으로 함께 저장합니다.
2. **보는 사람별로 새로 만듦**: 화면으로 나가는 것은 `worker/lib/fakeArtist.ts` 의 `buildFaView()` 하나뿐입니다. 전체 객체를 보내고 화면에서 숨기는 방식이 아니라, 받는 사람과 공개 단계에 맞는 필드만 골라 **새 객체**를 만듭니다. 아직 공개하지 않은 필드는 JSON 에 키조차 없습니다.
3. **가짜의 카드에는 제시어 필드가 없습니다.** 참관자·교사의 카드는 `null` 입니다.
4. **시점 누출 방지**: 최종 추측은 누가 가짜든 똑같이 20초이고, 가짜가 추측을 내도 다른 사람에게는 아무 메시지도 가지 않으며 방 버전도 오르지 않습니다 (본인에게만 스냅샷을 다시 보냄).
5. **제시어 목록은 서버 전용**: `worker/lib/fakeArtistWords.ts` 에만 있고 클라이언트 번들에 들어가지 않습니다. 단위 테스트가 `src/`·`shared/` 에서 이 파일을 가져오는지, 빌드 결과(`dist/client`)에 제시어가 들어 있는지 검사합니다.
6. **로그**: 제시어·역할·투표·추측은 로그로 남기지 않습니다.
7. E2E 테스트가 가짜·참관 방장·교사가 받은 **모든 WebSocket 메시지**를 이어 붙여 공개 전에 제시어·`fakeArtistId`·`votes`·`finalGuess` 가 없는지 확인합니다.

**알려진 한계 — 데모봇**: 데모봇은 교사 브라우저 탭에서 돌기 때문에 봇의 카드가 교사 탭으로 내려옵니다. 개발자 도구로 들여다볼 수 있으니 공정해야 하는 판에는 봇을 섞지 마세요. 봇은 혼자 리허설하는 용도입니다.

## 5. 한 획 입력과 네트워크

- 활성 포인터는 하나만 받습니다. 두 번째 손가락·펜은 무시합니다. `pointerup`·`pointercancel`·창 blur 에서 획을 끝내고 입력을 잠급니다.
- 점이 300개를 넘으면 모양을 거의 유지하며 솎아 냅니다.
- 그리는 중에는 150ms 마다 **획 전체**를 `fa.draft` 로 보냅니다 (응답 없음). 한두 개가 빠져도 다음 메시지로 복구됩니다. 서버는 검증 뒤 다른 사람에게 그대로 전달하고, 저장은 1.5초에 한 번 묶되 마지막 초안은 반드시 저장합니다.
- **지우고 다시 그리기**는 `revision` 을 1 올리는 명령이며, 서버가 받아들인 뒤에야 캔버스를 비웁니다. 그 전에 보낸 늦은 초안(낮은 revision)은 버려지고, 낮은 revision 의 확정도 거부됩니다.
- 확정(`fa.commit`)은 저장한 뒤에 응답합니다. 같은 요청을 다시 보내면 성공으로 답합니다(멱등). 끝난 차례·남의 차례의 확정은 거부됩니다.
- 재접속하면 내 카드와 그리던 초안이 그대로 돌아옵니다. 나간 사람(명시적 `나가기`)의 남은 차례는 건너뛰며, 가짜가 나가도 역할을 다시 뽑지 않습니다 (결과 공개에서 그대로 밝혀집니다).

## 6. 기다리는 동안 음악

- 파일: `src/lib/waitingMusic.ts`. **외부 음원 없이** Web Audio API 의 오실레이터로 직접 만든 짧은 5음 음계 아르페지오 + 낮은 음입니다. 코드가 곧 악보이므로 저작권·라이선스 문제가 없고, 추가로 내려받는 파일도 없습니다.
- 기본은 **꺼짐**. 학생이 "🔈 소리 켜기" 를 누를 때(사용자 동작) 켜집니다. 브라우저가 막으면 "소리를 켜지 못했어요" 만 보이고 게임은 그대로 진행됩니다.
- 앱 전체에 하나뿐인 인스턴스라 화면을 옮기거나 재접속해도 두 겹으로 울리지 않습니다. 탭이 안 보이면 멈춥니다. 음소거·음량 조절·끄기가 있고, 설정은 이 기기(`localStorage`)에만 남습니다.
- 그리기 단계에서 **내 차례가 아닐 때만** 흐르고, 내 차례가 되면 멈추고 짧은 알림음 + "내 차례예요!" 배너 + 탭 제목 변경으로 알립니다.

## 7. 저장소 변화

- 새 환경 변수·비밀·바인딩·외부 서비스는 없습니다. Durable Object 마이그레이션도 필요 없습니다 (새 테이블 없음).
- RoomObject 의 `room` 메타에 `gameMode`, `faSettings`, `fa`, `recentWordIds`, 참가자별 `faColor` 가 늘었고, 비밀 상태는 새 키 `faSecret` 에 둡니다. 이전 데이터는 읽을 때 기본값(그림 이어말하기)으로 채웁니다.
- 다시 하기·방 닫기·만료 때 `faSecret` 도 함께 지웁니다. 보관 기간(24시간)은 기존과 같습니다.
